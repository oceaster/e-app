e-server desktop client for Windows 10+ (x64), Ubuntu, Arch Linux and Linux AppImage (x86_64). Install the client, connect to your private network or VPN, and enter your e-server HTTPS address. No server credentials are bundled into these installers.

The name under the sign-in card is the app's own: it reads `e-app <version>`, as the repository is called, instead of the server product's name.

The sign-in screen is the website's own page, not a look-alike. It is the same document the Easter Company sites serve — the same markup, the same stylesheet, copied file for file and checked byte for byte by a test — so the panel, the type, the provider rows, the fields, the footer and the light palette are the site's, in both themes, and stay the site's as the site changes.

Two things behave better on the first screen: the card no longer stretches to the window, and the waiting mark beside "Signing in to Easter Company…" is the same ring the sites show. The window no longer flashes a dark colour its own page never uses.

Windows installers are currently unsigned. SmartScreen may warn; verify the source repository and SHA256SUMS before running. Linux AppImage may require FUSE 2. macOS, ARM and mobile clients are not offered.
